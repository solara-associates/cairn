# R4 cloud-touching acceptance checklist

Applies to every unit from **785 onward** — the first unit in R4 that needs a real
GCP project, a real service account, or a real IAM binding. Units 780-784, 787,
790, 792, 793 are cloud-free and are not covered by this checklist (R-GATE-01 and
the existing conformance suite already cover them). Written against
`cairn-r4-briefs.md` §2 (cloud access design), ADR-009 (immutable revisions and
approval-bound execution), ADR-010 (operation classes and governed
customer-environment mutations), ADR-016 (UK-only launch jurisdiction),
`docs/residency/uk-residency-matrix.md`, and `~/.config/architectural-rules/
projects.yaml` (the local write-guard's project allowlist and `iac_allowances`
list).

No item below is satisfied by code existing. Every item names what actually has
to run — a test, a CI gate, or Allan's own hands — before the unit it applies to
can be called done.

## Notes

- Items 1, 2, 3, 8, 9 apply to **every** cloud-gated unit uniformly — they are
  boundary conditions, not per-story features, so a later unit cannot treat an
  earlier unit's proof as having already covered it for the project as a whole.
  Each unit re-proves them against its own real call.
- Item 10 is the only item with no automated check by design — it is a
  deliberately manual, Allan-only cleanup step, tracked here so it is not
  silently forgotten once the cloud-gated units stop producing new PRs.
- 788/789's "rollback" is drift reconciliation and a Terraform-level apply, not
  a second independent rollback proof — 786 and 791 are where real rollback is
  actually proven end to end; this checklist does not double-count 788/789
  against item 11 beyond the reconciliation they already claim.
- This checklist does not relax or replace the existing conformance rules
  (`tools/conformance/rules.yaml`, 23 mandatory rules) or R-GATE-01/R-MUT-01/
  R-MUT-02/R-OUTBOX-01 specifically — it is additive, for the real-cloud
  boundary those rules were written before a production adapter existed to
  exercise.
